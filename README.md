# TerraSentinel — Landslide Early-Warning System (LEWS)
### Smart India Hackathon (SIH PS 26001) • Pilot: Eastern Himalayas (Sikkim)

> ### ⚠️ Data Status (Updated October 2026)
> - **Landslide Events**: The events in `backend/app/data/gsi_landslides.json` are a **synthetic placeholder inventory** generated by `ml_pipeline/build_gsi_dataset.py` to build and test the software pipeline. They are not direct GSI records.
> - **Susceptibility Layer**: `sikkim_susceptibility.geojson` is a simplified corridor placeholder, not official GSI NLSM shapefiles.
> - **Baseline Metrics**: Early metrics were computed on synthetic scaffolding data and do not represent field-deployed performance.
> - **In Progress**: Rebuilding on cited real events (NASA COOLR/GLC, Sikkim SDMA and GSI reports), official GSI Bhukosh NLSM polygons, corrected 0–28 cm soil moisture ingestion, and a learned physics + ML meta-learner. Verified results are published in `fixkit/`.

## 🌟 Key Features

1. **Dual Hazard Assessment Engine**:
   - **Physics-Informed Stability Core**: Regional Intensity-Duration (I-D) power-law thresholds ($I = 43.26 \cdot D^{-0.78}$, Harilal et al. 2019) plus infinite-slope Factor of Safety with Monte Carlo strength uncertainty ($P(\text{FoS} < 1)$).
   - **Monotone Machine Learning Ensemble**: XGBoost with monotonic constraints (increasing rain, soil moisture, or slope cannot lower hazard) fused via an L2 logistic meta-learner.
   - **Explainable Diagnostics**: Single source-of-truth mathematical decomposition into Static Susceptibility, Dynamic Telemetry, ML Confidence, and Physics Indicators with actionable directives for SDMA, District Magistrates, and Border Roads Organisation (BRO).

2. **Interactive GIS Command Center (Leaflet Map)**:
   - Dynamic dark, satellite, and topographic basemaps with precomputed 30m SRTM elevation and Horn slope gradient.
   - Color-coded hazard pins (Green: Low, Yellow: Moderate, Red: High/Critical).
   - Point Inspection Tool: Click anywhere in the pilot region to evaluate real-time slope hazard metrics with clear "outside coverage" states.

3. **Historical Replay Mode**:
   - Interactive 48-hour timeline scrubber for real historical landslide events (e.g., *Mangan June 2024 Event*).
   - Calculates hour-by-hour cumulative antecedent rainfall to evaluate lead times prior to slope failure.

4. **"What-If" Precipitation Stress-Tester**:
   - Live rainfall multiplier slider (+10% to +100%).
   - Monotonically evaluates slope failure sensitivity across all regional corridors.

5. **OASIS Common Alerting Protocol (CAP v1.2)**:
   - Standards-compliant CAP v1.2 alert drafting, digital signature, and officer review workflow for national dissemination via SACHET.

6. **Active Alerts Queue & Field Incident Desk**:
   - Real-time automated warning dispatch.
   - Field officer / SDRF report submission modal with geolocation and photo evidence tagging.

## 🚀 Quick Start

### 1. Requirements
- Python 3.10+
- Dependencies: `fastapi`, `uvicorn`, `scikit-learn`, `requests`, `pydantic`

### 2. Installation
```bash
cd landslide-early-warning-system
python -m pip install fastapi uvicorn scikit-learn requests pydantic
```

### 3. Run Application
```bash
python run.py
```
- Open Web Command Center: `http://127.0.0.1:8000`
- Open Swagger API Docs: `http://127.0.0.1:8000/docs`

### 4. Run Automated Tests
```bash
python tests/test_api.py
```

### 5. Train / Validate ML Pipeline
```bash
python ml_pipeline/train_and_validate.py
```

## 📡 API Specification

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/risk?lat={lat}&lon={lon}&rain_boost_pct={pct}` | Computes point hazard score, category, weather, slope & explanations |
| `GET` | `/api/stations?rain_boost_pct={pct}` | Returns all monitoring posts with current risk evaluations |
| `GET` | `/api/landslides?bbox={bbox}&from={date}&to={date}` | Queries historical landslide inventory records |
| `POST` | `/api/report` | Submits field officer ground observation / incident report |
| `GET` | `/api/reports` | Lists submitted field incident reports |
| `GET` | `/api/alerts` | Lists active high-priority landslide warnings |
| `POST` | `/api/simulate` | Executes multi-station What-If rainfall surge simulations |
| `GET` | `/api/replay` | Returns benchmark historical event progressions for replay |
| `GET` | `/api/validation` | Returns model benchmark analytics & confusion matrix |

## 🏛️ Authoritative Data References

- **GSI National Landslide Forecasting Centre (NLFC) / Bhu Sanket**: Historical landslide catalog and 1:50k NLSM susceptibility mapping.
- **India Meteorological Department (IMD)**: Real-time and forecast precipitation data.
- **Open-Meteo**: High-resolution meteorological and multi-depth soil moisture data (0-10cm, 10-40cm).
- **USGS / NASA**: SRTM 30m Digital Elevation Model (DEM) for slope gradient computation.
- **NASA LHASA**: Landslide Hazard Assessment for Situational Awareness framework.
